## 🎮 通用玩法

每个游戏都支持两种模式：

### 单人模式
- 系统随机生成目标值
- 玩家通过交互操作，尽量接近目标
- 误差越小，评价等级越高
- 无限回合，随时可返回菜单

### 双人Battle模式
- 支持 BO1 / BO3 / BO5 / BO7 / 无限赛制
- 两名玩家轮流操作，误差更小者赢得该回合
- 达到赛制回合数后判定最终胜负

## 💧 水一把 (WATER)

### 规则
- 系统随机生成目标水位（0%~100%）
- 玩家**长按**水杯注水，水位持续上升，**松手锁定**
- 水位只升不降，超过100%视为100%
- 尽量让最终水位接近目标百分比

### 操作
| 模式 | 操作方式 |
|------|---------|
| 单人 | 鼠标按住/触屏长按 水杯注水，松手确认 |
| 双人 | 两名玩家分别操作各自水杯 |

### 评分标准
| 误差范围 | 等级 |
|---------|------|
| ≤1% | **S+** 🌊 |
| ≤3% | **S** |
| ≤5% | **A** |
| ≤10% | **B** |
| ≤20% | **C** |
| >20% | **D** |

## 📐 角一把 (ANGLE)

### 规则
- 系统随机生成目标角度（0°~360°）
- 玩家拖动量角器上的**蓝色圆点**旋转可动边
- 尽量让蓝色射线与目标角度一致
- 点击「确定」提交答案

### 操作
| 模式 | 操作方式 |
|------|---------|
| 单人 | 鼠标拖拽/触屏拖动 圆点旋转量角器 |
| 双人 | 两名玩家分别操作各自量角器 |

### 评分标准
| 误差范围 | 等级 |
|---------|------|
| ≤1° | **S+** |
| ≤3° | **S** |
| ≤5° | **A** |
| ≤10° | **B** |
| ≤20° | **C** |
| >20° | **D** |

## 🌈 色一把 (COLOR)

### 规则
- 系统随机生成目标颜色（RGB全范围）
- 玩家通过**色相条 + 饱和度/明度色板**调配颜色
- 评分基于 **Delta E**（CIE Lab色彩空间距离）
- 点击「确定」提交答案

### 操作
| 模式 | 操作方式 |
|------|---------|
| 单人 | 拖动色相条选色相 → 在色板中点选饱和度(左右)和明度(上下) |
| 双人 | 两名玩家分别调配各自颜色 |

### 调色说明
- **色相条**（顶部彩虹条）：拖动选择色相 0°~360°
- **SV色板**（下方矩形）：左右 = 饱和度，上下 = 明度
- 实时预览显示在面板顶部

### 评分标准
| ΔE 范围 | 等级 |
|---------|------|
| ≤2 | **S+** |
| ≤5 | **S** |
| ≤8 | **A** |
| ≤14 | **B** |
| ≤20 | **C** |
| >20 | **D** |

## ⏱️ 秒一把 (SECOND)

### 规则
- 系统随机生成目标时长（0s~30s）
- 三步走：**展示目标 → 开始计时 → 掐表**
- 用默数的方式估算时间，误差越小越好
- 精度精确到毫秒（0.001s）

### 操作
| 模式 | 玩家1 | 玩家2 |
|------|-------|-------|
| 单人 | `空格键`：展示/开始/掐表 三合一 | — |
| 双人 | `F键`：开始计时 + 掐表 | `J键`：开始计时 + 掐表 |

### 按键流程（单人）
1. 点击「开始」→ 显示目标时间
2. 按 `空格` → 开始计时（圆点变蓝，显示"默数中"）
3. 再次按 `空格` → 掐表（圆点变绿，显示"已停"）

### 按键流程（双人）
1. 点击「开始」→ 显示目标时间
2. 两名玩家各自按 `F`/`J` 开始计时
3. 各自按 `F`/`J` 掐表
4. 两人都掐表后自动结算

### 状态指示
| 状态 | 圆点颜色 | 含义 |
|------|---------|------|
| 待机 | ⚪ 灰色 | 等待开始 |
| 准备 | 🟡 黄色 | 目标已显示，按对应键开始 |
| 默数中 | 🔵 蓝色 | 计时进行中 |
| 已停 | 🟢 绿色 | 已掐表，等待结算 |

### 评分标准
| 误差范围 | 等级 |
|---------|------|
| ≤0.1s | **S+** |
| ≤0.3s | **S** |
| ≤0.5s | **A** |
| ≤1.0s | **B** |
| ≤2.0s | **C** |
| >2.0s | **D** |
